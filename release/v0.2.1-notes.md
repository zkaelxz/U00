# Baihe Studio v0.2.1

Install by running `BaiheStudio-Setup-0.2.1.exe` once on every PC, also on a copy that runs as the background service. Windows asks for administrator permission: this one run is what lets package installs finish by themselves later. Windows SmartScreen warns on first run because the installer is not code-signed.

Back up your library before you update (Library > Library tools > Backup).

## New
- Optional packages (such as the Korean text reader's GPU build) now install by themselves a few minutes after you queue them, once no job or Live session is running, and Baihe restarts itself. Cancel stays available, and Diagnostics shows the last result.
- Covers: a "Refresh cover from site" button for comics and videos, and comics can use the site's series picture or a page or frame you crop. Nothing calls a site by itself.
- Library: grouping is now one-click buttons (No grouping, By series, By media type, By status). Series headers have Rename and Delete, and a Show covers switch turns pictures off on this device.
- Settings has a Sharing page with its own list, ordered by owner or title, and an owner filter.
- Vocal separation uses the Mel-Band RoFormer FV4 model by default. Press Download on its Diagnostics row once to switch.
- Scanlate: floating art text gets a soft halo and shadow.
- Sources: Manage sources lists the extension-only sites read-only, and a site that moved to a new numbered address is found again by itself.
- Phone app: copied links from more comic sites are offered at any number, and it says once when the PC has not answered for an hour.

## Changed
- Soft look: one box and padding for every block, and a warmer, calmer light theme.
- Long lists on Jobs, Find, Library tools and Language packs scroll inside their block instead of making the page endless.
- Novel translation runs six lanes side by side on DeepSeek.
- Korean comic pages go back to PNG for the picture reader.
- Backups store already-compressed media instead of compressing it again, and say which copy was deleted and how many are left.
- Update: a preferred default model that the PC lacks is fetched overnight.
- Logs have a stats line per finished job, a daily summary, and Live and text reader stats, for the Send logs button.

## Fixes
- Review: a doubt from the meaning check no longer hides other flags on the line.
- Live looks up the stream while Whisper loads, and keeps glossary names out of Whisper's prompt.
- The 8600 port retries opening if it failed once.
- The Korean text reader's GPU install uses a build that works with Python 3.13.
- Voice clips for Qwen3-TTS voices get their spoken text written down when they have none.
- The phone says why Android would not start an update install.
- Video titles take the platform's thumbnail when you refresh the cover.
- Many smaller Soft look, Library and Settings fixes.
