# Baihe Studio v0.1.7

Install by running `BaiheStudio-Setup-0.1.7.exe` once on every PC, also on a copy that runs as the background service. Windows SmartScreen warns on first run because the installer is not code-signed. Later updates then install by themselves.

Back up your library before you update (Library > Library tools > Backup). The browser extension is now 1.2.15: unzip the new copy over its folder and press Reload in the browser's extensions page once; later versions reload by themselves.

## New
- Updates install by themselves, between 3 and 6 AM or after a day's wait, when nothing is running. An update that changes only Python packages no longer needs the full installer, and a failed one is rolled back.
- The extension reloads itself after a PC update, and the phone app updates silently on Android 12 and later.
- The Library can group series under a streamer.
- Comics have a built-in glossary of common Japanese, Korean and Chinese terms for Quick read and Scanlate.
- People can delete titles they made from any device (up to 100 titles for a member).
- One-click translate from a pasted video link works from any device for people allowed to import and start jobs.

## Changed
- Quick read is much faster: the PC downloads the pictures itself, reads six pages at once, waits for a free engine instead of failing, and sends smaller pages back.
- Quick read follows a chapter split into parts, opens on the first page, has a Cancel button, shows a live ready counter, and shares one name list across a title's pages.
- Quick read translates title logos and signs drawn on the art, and re-reads unclear text at full size.
- Chinese and Korean comic text is read several times faster, and balloons are found on the GPU when it has room.
- Erasing keeps banner strips, chapter tags and rules intact, and cleans burst balloons and art captions better; English is bigger in roomy balloons.
- Grab keeps reading pages while the app is in the background, has a visible address box, matches the app's look, and explains a refused phone token.
- The phone app checks for a newer build each time Baihe is reopened.
- The extension captures without waiting for the tab to be shown and works with more readers.
- A transcription can run beside an online translation with the Source-match check on.
- Old translation versions are stored compressed, which saves space.

## Fixed
- Two Baihe installs on one PC no longer share the extension's connection.
- ASS export leaves the Actor column empty for an unnamed speaker.
- A site stamp misread by the text reader is no longer lettered as dialogue.
- Quick read never serves a page redrawn by an older version.
