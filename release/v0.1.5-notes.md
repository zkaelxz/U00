# Baihe Studio v0.1.5

Install by running `BaiheStudio-Setup-0.1.5.exe`. Windows SmartScreen warns on first run because the installer is not code-signed.

Back up your library before you update (Library > Library tools > Backup). Updating from 0.1.4 does not ask for a backup. Later updates do. The browser extension is now 1.2.8: unzip the new copy over its folder and press Reload in the browser's extensions page.

## New
- An Add box at the top of the Library is the one place to start a title: paste a link, or choose or drop a file.
- A Watch and Listen page plays a title with its lines following along, so you can fix the line you hear.
- Mark a line Wrong or Mixed, and see marked lines in their own view.
- Faster speakers: tap a suggested speaker, press a speaker's name to change it, hear a sample of each speaker, and try a voice with Test voice.
- Review History compares two saved versions side by side.
- Re-translate selected lines with an engine and model you pick.
- Optional "Run 3 times, review differences" shows only the lines where the runs disagree.
- A title keeps its own glossary terms when it joins a series, and Copy to series adds them to the series.
- Library tiles name the next step, such as "Translate 5 lines" or "Read from page 12".
- A resource monitor warns about GPU temperature and memory, RAM, CPU and free disk.
- Guided remote access setup, with a form for the sign-in settings.
- Title import can also bring the voice bank and settings, and can join each series to one with the same name.
- Notifications say "Waiting for you" when a run stops for you, and Discord messages are cards.
- The comic reader can start a new chapter at a page.
- The browser extension has typeset look settings, a second lettering font, and comic pages that appear as each one finishes.

## Changed
- A new look: new fonts, a clearer top bar and menu, and a redrawn Simple title page and Review.
- Settings is now seven tabs, each with one job, and one Updates card.
- Review's tools are in four tabs: Look for problems, Change many lines, Records and Finish.
- Shorter, plainer wording on buttons, tooltips and messages.
- Lines start and end closer to the speech.
- Chinese titles use Breeze-ASR-25 once it is downloaded.
- A line whose speaker the detector was unsure of is left blank instead of guessed.
- The translate cost estimate is closer to what a run really costs, so it reads higher than before.
- Spend caps also count hosted Ollama models, the assistant and the Reader's Ask.
- Stream translations with Gemma 4 use a simpler prompt by default.
- Comic lettering matches the original colour by default, and follows its slant and fade.
- Automatic backup is on by default, and a banner says when the last backup failed.
- GPU work pauses or stops while the GPU is short of memory or too hot.

## Fixed
- "Transcribe this gap" starts its run and fills in the new line.
- A translate run no longer writes English onto a line whose source changed during the run.
- Fix flagged keeps the flag when the new English fails its checks.
- An odd model reply about a line's emotion no longer loses a paid run.
- A very long episode's summary no longer times out.
- Many comic lettering and cleanup fixes.
- The comic Simple page updates when a job finishes.
- A novel chapter move stopped part-way is finished or undone at the next start.
- Subtitle import keeps notes, tags, speakers and flags on lines it matches.
- Review works on phones and narrow windows without anything cut off or covered.

## Security
- An ended sign-in session can no longer come back.
- Voice bank files stay inside the voice bank folder.
- The extension needs edit permission for every change it makes.
- Releases are checked more strictly before an update installs.
- The bundled web server has its security updates.
