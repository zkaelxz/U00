# Baihe Studio v0.1.5

Install by running `BaiheStudio-Setup-0.1.5.exe`, and check the download against its `.sha256`. The installer is not Authenticode code-signed, so Windows SmartScreen warns on first run. The `.sig` file is a release signature for the in-app update check only.

## Before you update
Back up your library first (Library > Library tools > Backup > "Back up library"). This release adds a table to the library (`capture_notes`, the extension's capture notes). A PC updating from v0.1.4 runs v0.1.4's updater, which does not ask for a backup. Later updates do ask.

## Changed since v0.1.4
- Review: History can compare two saved versions of the lines side by side, with the changed words marked, next and previous change, and a per-line "Use this" (one-step undo). History now keeps the 20 most recent saves instead of 10. "Re-translate selected lines" runs chosen lines again with an engine and model you pick. An optional "Run 3 times, review differences" action runs an ordinary Translate three times after you confirm the estimate, then shows only the lines whose runs differ so you pick one per line.
- Streams: Gemma 4 stream runs use a plain prompt by default (names and special terms from the glossary, no neighbouring lines, 10 lines per request); a glossary term's aliases show beside it. A setting in Settings > Translation switches it off. A title that has already been run keeps its remembered batch settings, so it may not pick up the plain prompt's batch size.
- Translation: Luna's reasoning defaults to Less for Translate runs. The AI engine picker says which model is recommended for comics, streams and novels. Bulk batch results are checked for junk replies like live runs are, and paid results are kept when an apply fails. Ollama cloud models (`-cloud` tags) and the maintenance assistant's calls count against the monthly cap, and the Reader's Ask is held to it and logged.
- Glossary: suggested terms include recurring names and nicknames and slang found in the transcript; an inferred meaning shows as Low.
- Translate page (comics): warnings are grouped, harmless ones are folded, and a Warnings menu in the reader bar has Previous and Next warning. The boxes a warning names are marked.
- Navigation: the first stage is called Transcribe (comics and novels keep Media), the Library has one Start button, Discover and Sources are one entry called Find, and the Run tab is called Run. Old addresses still open. Reduced-motion scrolling is respected, Shaky and Source changed have tap help, and Snap times is shown as text.
- Library: a title's details popup shows its series and lets you add one there, a Series action in the selection bar moves several titles at once (editability is checked and failures are reported per title), and it shows the last extension captures' closing lines. A subtitle import pairs repeated identical lines in order and keeps notes, emotion tags, speaker and flags on lines it matches; the preview says how many notes would still be deleted. A library reset snapshots first, refuses if followed-series links cannot be cleared, and tells you when the unlink failed.
- Novels: a chapter move that a hard kill stopped is finished or undone at the next start; a second copy of the app waits a bounded time for a live move, and a title with no folder refuses the move with a message. The move lock is left out of backups.
- Comics: the reader can start a new chapter at a page for titles saved before chapters were recorded.
- Live: each chat message shows when it was sent.
- Updates and release safety: a full install asks for a backup when the update changes the library, as the app-only update already did. Setup's elevated service step runs only from a copy checked against the installer. The release manifest is signed and the app trusts its schema hash only with a valid signature. A pre-release is published for each tag only when the tests passed at that commit, and promoted to a full release by a separate approved job. Dev copies update only to a commit whose tests passed. A rolled-back update says so when the library had already changed, or when the app cannot tell.
- Security: the extension's write routes need lines.edit and jobs.start, and a member without jobs.start no longer triggers the title-naming AI call. Capture notes drop token-like link paths and never block a capture.
- Android: the phone app is built as a non-debuggable release signed with the same key. Updating over an old debug build was not tried.
- Browser extension 1.2.6: the typeset switch shows on every tab, burst balloons are detected, typeset look settings (alignment, size, outline, erase strength, balloon fill) were added, text translate follows the save switch, and each chapter capture's closing line is kept in the app log. Unzip the new copy over the folder and press Reload at `chrome://extensions`; the card must read 1.2.6.
- Tests and tools: a non-blocking accessibility report runs with the browser tests, and the flaky tests behind red base runs were fixed.

## Known limits
- Everything above was checked with mocked and Playwright tests only. Nothing was run through the real installer or updater, a real phone, real Chrome or Edge extension pages, or a real paid or local engine. "Re-translate selected lines", "Run 3 times", the compare view and the stream plain prompt were not tried with a real engine.
- To test on a real PC (Kae): update from v0.1.4 with a backup taken first; a real non-admin Setup; the new extension on a real page; Review History compare and re-translate on a real title.
- Android: the in-place update from an old debug build was not tried.
- Setup's elevated service step was not run on a real PC with the background service.
- The v0.1.4 limits still apply where not stated above.
