# Baihe Studio v0.1.3

Install by running `BaiheStudio-Setup-0.1.3.exe`, and check the download against its `.sha256`. The installer is not Authenticode code-signed, so Windows SmartScreen warns on first run. The `.sig` file is a release signature for the in-app update check only.

## Changed since v0.1.2
- Novels, chapters: a saved chapter can be renamed (its text, the chapter list and its title line change together) and moved earlier or later. A novel's title page can translate one chapter again. The Reader has a chapter list with search and each chapter's translated state.
- Glossary: Find terms can scan one saved chapter, and Scan all chapters scans the whole novel. The Terms table has search, sort and a match count. The glossary can be downloaded as JSON, with the same columns as the CSV. The Chinese default pack (zh-common) translates 姑姑 as Auntie (a father's sister; Aunt is an option for a narrator, and 王姑姑 becomes Auntie Wang); it applies only when that pack is switched on, and a title's own glossary term still wins.
- Local Ollama translation sends temperature 0 and a fixed seed, so the same text gives the same result on each run. Claude, OpenAI, Gemini and DeepSeek are unchanged.
- Docs: the browser extension page is brought up to date.

## Known limits
- Everything above was checked with mocked and Playwright tests only, not on a real novel through the app.
- Scan all chapters was never run against a real, paid scan.
- Translate again was tried only with the offline test engine, not with a real translation engine.
- With local Ollama now repeatable, if every line of a batch comes back without a result, the retry repeats the same request and gets the same answer, so those lines stay untranslated. Redo them with Translate again.
- Moving a chapter: if a move is interrupted, the chapter list can be missing until it is rebuilt. While it is missing, the browser extension's duplicate check fails, so the same page captured twice would be appended twice. A crash recovery has to restore the raw file and the chapter list together, or use the line history.
- The v0.1.2 limits still apply: nearly all of v0.1.2's changes (comics, extension, novels, glossary, models) were mock-tested only, the extension was not run on real sites for that release, and narrow balloons can still break a long word with a hyphen.
- v0.1.2 is already published and stays published; v0.1.3 is the release to install.
