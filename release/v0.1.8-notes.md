# Baihe Studio v0.1.8

Install by running `BaiheStudio-Setup-0.1.8.exe` once on every PC, also on a copy that runs as the background service. Windows SmartScreen warns on first run because the installer is not code-signed. Later updates then install by themselves.

Back up your library before you update (Library > Library tools > Backup). The browser extension is unchanged (1.2.15).

If you follow channels, open each one's Edit settings once and press Save, so it picks up the new per-channel settings.

## New
- Comics: Quick read on the phone has pinch and double-tap zoom, volume-key paging and keeps the screen awake. It translates the next chapter before you reach it, and a long press on a page saves, shares or sets it as the cover.
- Chapter read marks, bookmarks and Next unread for each account, and a Library Reading filter with unread counts on comic cards.
- Quick read text is read on the GPU when there is room (the first read downloads about 140 MB), many times faster.
- Image text translate for single pictures, and comics can be imported from CBZ files.
- Subtitles inside a video file, and subtitles drawn into the picture, can be read and translated.
- Fullscreen landscape on the phone, and a Library tab bar with Continue cards, oldest first.
- Delete user, and the add buttons now sit at the top of each screen.
- An Updates page that shows what changed in each version, and a Quality card in Diagnostics.
- Topic chapters for long streams, an emote filter, and site captions as a subtitle source.
- Live uses the series glossary names to hear names correctly, and each followed channel has its own settings.
- Voices can be private to their owner.
- Presets are grouped by language.

## Changed
- Transcribing a Chinese stream with vocal separation is almost twice as fast (about 11 minutes instead of 20 for two hours), and a re-run reuses the separated voice.
- Gemma 31b cloud is the default translation model, with hosted models on by default. The local translategemma 27b and 12b are gone.
- Members get their settings picked for them: Translate, Live and the Reader choose the engine, and Gemma cloud is the member default. The spending-limit message no longer mentions Ollama.
- "Think harder" and "Check and revise" are removed. The Release preset keeps Auto QC only.
- Glossary scans use the model the title translates with.
- Old translations are stored compressed.
- Text and Read pick the image model for you.
- Downloads of Twitch highlights and similar streams fall back to ffmpeg, and say why when a stream cannot be fetched.

## Fixed
- Several smaller comic, Live, Reader and member-account fixes.
