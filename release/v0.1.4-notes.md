# Baihe Studio v0.1.4

Install by running `BaiheStudio-Setup-0.1.4.exe`, and check the download against its `.sha256`. The installer is not Authenticode code-signed, so Windows SmartScreen warns on first run. The `.sig` file is a release signature for the in-app update check only.

## Changed since v0.1.3
- Novels, chapters: Import from link stays available after translation starts, and adding chapters is safer: a stop after the lines are saved no longer repeats them, a changed text blocks adding more, and a failed replace keeps its marker. The Reader's chapter list shows reviewed state, translated titles and volume headings.
- Glossary scan: it asks a cut-off passage again in halves, proposes aliases, and proposes pronouns and people for the cast found in the text. A she/her, he/him or they/them note is kept only when its quote contains a pronoun, title or kinship term (Chinese titles; Japanese and Korean skip this check). Applying a scan no longer replaces a pronoun note you wrote. Aliases are capped at 50 per term and restored word replacements at 500. Word replacements copy with a series' terms and restore with a title.
- Security: error text redacts key names and long key names, `.env` is written owner-only, and redirect bodies are handled safely. Pip, upgrade checks, yt-dlp and the browser install no longer inherit secret environment variables (names with KEY, TOKEN, SECRET, PASSWORD and the like). Full backups leave out `library/logs`, which can hold raw server output.
- Sources: the fetcher no longer reads proxy settings, system proxy or CA bundle variables, or `.netrc` from the environment. If you need a proxy for Sources, set it in the Sources settings. "Will this site work?" now shows the recorded site terms as information and still refuses nothing.
- Japanese hard-subs now default to Auto (RapidOCR first, then PaddleOCR, then Tesseract), as Chinese and Korean already did, so Tesseract does not need to be installed for the default path. A title with a saved choice is unchanged.
- Installer and tools: Diagnostics can install ffmpeg in one click into the app's own `tools` folder. The service can open a title's folder and says where it is. Setup accepts the app's `android` folder in the data folder. Uninstallers name the app's data folders they leave behind, and Remove everything also deletes `voice_engines` and `playwright_browsers` in a data folder Setup did not create. The README says Setup asks for administrator permission only if you tick the background service box.
- Android: the phone shows one icon, Baihe Studio. Baihe Grab opens from that icon's long-press shortcut, from a link to another site tapped in the app, or from Android Share. A phone that already has the app keeps the second icon until the app is updated.
- Browser extension 1.2.1: the options page and the popup say when the loaded copy is older than the app's, and the popup has a Chapters box. Chrome and Edge never update a folder-loaded extension, so unzip the new copy over the folder and press Reload at `chrome://extensions`; the card must read 1.2.1. A copy older than 1.2.0 needs that manual reload before it can warn.
- Extension imports: saved pages are filed under a chapter. The number is read from the page address (for example `no=`, `episode`, `chapter`, or `/chapter-7`); without one, a capture becomes one chapter named "Imported" with the date and time. Titles imported earlier stay "Chapter unknown". When Fill is on, a new title that has only its original name gets an English name from one small AI call on the extension's engine, checked against the person's paid permission; later chapters never spend again.
- Comics: Open folder works for comic titles on the PC itself (the full path is shown only on that route). Redo controls in Scanlate are easier to find, and a read-through shows its progress. A new setting, "Match the original lettering colour in comic balloons", is off by default and its thresholds are a first guess. The Packages page explains a locked folder in plainer words. A second new setting, "rectangle layout" for balloon text (Settings > Translation, off by default), sets text in the largest rectangle that fits inside a balloon so lines are even instead of staggered; it falls back to the outline layout when the rectangle is too small. Whether it looks better is untried on a real page.
- README: the feature list is grouped by area, one line per feature.
- Google sign-in asks only for your email address (`openid email`), not your name or picture.

## Known limits
- To test on a real title (Kae): Open folder on a comic through the service install; the lettering colour setting and a redo on a real page; the extension on a real site (chapter label and English title); one real novel with add chapters, move, translate again, rename and cast. The novel work and all of the above are mock-tested only.
- Everything above was checked with mocked and Playwright tests only. Nothing was run through the real installer, a real Google sign-in, a real phone, the real ffmpeg download, real Chrome or Edge extension pages, a real novel with a paid engine, or real Japanese hard-sub frames.
- The ffmpeg installer pins the download's size and SHA-256; the pinned values were compared with the publisher's page by the author of the change and not re-checked here.
- Hard-sub reading quality for Japanese with RapidOCR was not measured on real frames. Tesseract stays optional and was never tested on Windows.
- Sources through a proxy or corporate root CA that you only set in the environment will now fail; set the proxy in the Sources settings.
- The gender check can still reset a correct gender to "unclear" when a quote uses a title the marker list does not know, and a note like "my teacher; she/her" can still be replaced when you Apply with overwrite ticked.
- The uninstall scripts do not yet list the `tools` folder among the data folders they leave behind.
- The Deno install through winget still inherits the full environment.
- The v0.1.3 limits still apply where not stated above.
