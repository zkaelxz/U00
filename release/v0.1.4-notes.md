# Baihe Studio v0.1.4

Install by running `BaiheStudio-Setup-0.1.4.exe`. Windows SmartScreen warns on first run because the installer is not code-signed.

The browser extension is now 1.2.1: unzip the new copy over its folder and press Reload in the browser's extensions page.

## New
- Diagnostics can install ffmpeg in one click.
- The browser extension says when your copy is older than the app's, and its popup has a Chapters box.
- Pages saved from the extension are filed under a chapter, and a new title can get an English name.
- The novel Reader's chapter list shows reviewed state, translated titles and volume headings.
- Glossary scan suggests aliases, pronouns and people for the cast.
- Open folder works for comic titles.
- Two optional comic settings: match the original lettering colour, and an even rectangle layout for balloon text.

## Changed
- Import from link stays available after a novel starts translating, and adding chapters is safer.
- Applying a glossary scan no longer replaces a pronoun note you wrote.
- Japanese hard-subs use Auto text reading by default, like Chinese and Korean.
- The phone app shows one icon. Baihe Grab opens from its long-press shortcut or from Share.
- Comic redo controls are easier to find, and a read-through shows its progress.
- Sources use only the proxy set in Sources settings, not one from the environment.
- Google sign-in asks only for your email address.
- Uninstall names the data folders it leaves behind.

## Security
- Error messages hide key names.
- Installs and updates no longer get your secret environment variables.
- Full backups leave out raw server logs.
