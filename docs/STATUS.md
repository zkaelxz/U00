## Where the app is

What works:
- React + FastAPI is the only app: `python -m api` serves the API and the built React app (`start.bat` runs it). Streamlit is gone (`pre-streamlit-removal` tag, `legacy/streamlit` branch).
- Remote access: Google sign-in, ownership, deny-by-default permissions, the D5 admin and household listeners, private-by-default sharing with an admin Sharing screen and the admin audit log are merged. `docs/route-permissions.md` is enforced by `tests/test_api_permissions.py`. Sign-in is optional and off by default (`BAIHE_API_AUTH`); with it off only direct loopback requests are served. The Caddy template (`deploy/caddy/`), the Caddy helper (`installer/caddy`), owner-run `enable-remote` / `disable-remote` / `status` and the certificate/DDNS banner are in the repo. Don't expose the API beyond loopback until the owner's LAN and router checks are done. What is exposed and what is deliberately not defended: [`threat-model.md`](threat-model.md).
- Windows installer with hash-pinned wheels, the boot service with its stored port (`service.py set-port`; `BAIHE_API_PORT` only on a fresh install), the Setup lock, auto-backups (2 daily and 2 weekly per library), one person's export and import from a backup file (PC only; tracked series, the voice bank, settings and other profiles' data don't travel), Library tools with five tabs (Organize, Activity, Backup, Storage, Data folder) and a restorable Trash, sources.db inside backups and restores (so tracked series and extension-only markers survive), and a library temp folder swept at startup and left out of backups.
- Transcription: Whisper (default `large-v3` on CPU and GPU, `default_whisper_size()`; `large-v3-turbo` is the fast option; medium and below are hidden from the pickers except Live, `whisper_models.selectable_whisper_sizes`), the opt-in Qwen3-ASR backend with its own speech detection and automatic language, forced alignment, re-timing of existing lines with the Qwen3 aligner, word timings stored per line and used by every split, per-line spoken language (mixed-language titles), hallucination guards (silence threshold off by default), time estimates from your own runs, the optional ASMR voice detector, "Check timing", "Transcribe this gap", bulk re-transcribe, and a waveform timeline in Review. Measurements: `docs/asr-experiments.md`.
- Translation: Claude, Gemini, DeepSeek, OpenAI and Ollama (local and cloud models); DeepL, Google, LibreTranslate and NLLB are removed. Batches start at scene breaks, thinking is off by default with a per-run option, glossary proposals with counts and a per-series ignore list, built-in language-pack glossaries, bounded glossary LLM calls with Cancel, cost tracking with an optional monthly cap (off unless set in Settings > Costs or `.env`),, chrF similarity in Benchmark Lab (optional sacrebleu), and Lab cost estimates that count hidden reasoning tokens for reasoning models (output x4, `estimate_uncertain` flag; the UI does not show it yet).
- Review: tick-box selection, Compare transcription, re-split presets with a dry-run preview, the English "Fix common errors" pass, speaker naming and merging with undo, line history with a preview before restore, playback and timing hotkeys, and a pop-out window.
- Live: capture fetched in Python through a guarded egress proxy (`services/egress_proxy.py`, `live_fetch.py`) and piped to ffmpeg's stdin; ffmpeg never opens a URL. Fixed-length chunks (default 20 s), each transcribed whole by Whisper with a few seconds of the previous chunk's audio prepended and the re-heard overlap removed by exact text match; translation runs on its own thread, one id-keyed request per chunk, so Whisper never waits for it. Transcript first and translation later, captions over the video with an automatic video delay, and a caption-lag figure in the status. The LocalAgreement-2 code (`live_agreement.py`) is written and tested but not wired into Live.
- Sources: the adapters in `sources/adapters/`, per-source pace levels with automatic slowdown, the browser extension with whole-chapter capture (per-device tokens can be created and revoked, but no extension route accepts one yet; the bridge still uses the shared loopback token), subtitle file import (SRT/VTT/ASS/LRC) and LRC export, and lightnovel-crawler as a separate program.
- Navigation: one nav registry (`frontend/src/nav/navItems.ts`); from 600 px a side nav that floats as a pill (icons only below 900 px) or docks as a full rail, at the left, right, top or bottom edge (Settings > Account and display > Display, `nav/navDock.ts`); a drawer and a phone bottom bar (Library, Make, Jobs, More) below 600 px; a Back button, an "Open in new window" slim second window (#1554), breadcrumbs inside titles, a per-person Menu items card (Settings > Account and display), Ctrl+K for pages and stages (not titles or lines), a Jobs page, and a Settings upload size limit (default 20 GB; library restore stays capped at 2 GB). `docs/design/navigation-proposal.md` has the build status.
- Jobs: the job machinery lives in `jobs/` (split out of `background_jobs.py` in #1363; `docs/background-jobs.md`). One job surface (the Jobs page and the job panel with its Last run card and no-progress warning; the Diagnostics jobs panel is retired). Process jobs hand results back through a file for large ones, are reaped before they report done, and GPU work that must be killable runs through `services/gpu_process_job.py` (compare transcription and fix-flagged hear). URL media runs yt-dlp in a killable child (#1055). Phase 0 of the jobs plan (the QC queue: bounded AI calls, force stop, cancel checks, process-job hardening) is complete; Phase 1 PR A is merged (#1058, `jobs/job_store.py`, the only writer of `job_records` rows); the in-memory dict still decides what a job this process runs does next, and the parts after PR A are not merged.
- Outbound HTTP: `lib/http.py` is the one fetch front door (guard on every redirect hop, pinned connection, byte cap, deadline); waves 1-4 are merged (#1046, #1054, #1057, #1070: `services/`, root modules, LLM engine POSTs and simple sessions, one guarded Session factory for the fetch ladder and live capture). `lib/` also holds `proc.py` (the one external-command runner), `cancellable_lock.py` and `settings_schema.py` (declared settings, one reader and the schema endpoint with generated Defaults, Spending and Advanced cards; parts 1-3 merged as #1062, #1068, #1071).
- Frontend: Settings has six tabs (Translation and keys, Costs, Notifications and backups, Account and display, Integrations, Performance and advanced) with a search box and foldable cards (one Expand all / Collapse all button per tab), Make subtitles is one screen on its own page in the Tools menu (the Library has a small button to it), Transcribe and Translate have Basic and More options views, and the UI says "title" (not "drama"), a Media stage (not Source) and Quick translate. Diagnostics has four tabs (Setup, Packages and installs, Models, System; "Models in memory" and Ports sit there, not in Settings) and its installs show a preview and can queue for restart when files are in use (`install_plan.py`, `pending_install.py`).
- Job queue: a Queue card on the Jobs page lines up Transcribe, Translate and Export subtitles items for titles and runs them one at a time, now or once at a set time (`services/queue_service.py`, `/api/queue`). Translate items are checked against the month spending cap first; after a restart a running item is Interrupted and a passed start is Missed, never run on its own. A Transcribe, Translate or Export item can change its step's settings for that item only (the title is not changed).
- Downgrade guard: `db.init_db` records the running version in the `app_version_last_opened` setting and refuses to open a library last opened by a newer installed version (`NewerDatabaseError`; `python -m api` prints one line and exits). A source checkout has no version, so it neither checks nor records.
- Browser-tier Sources (brief 67): `SourceAdapter.needs_browser` (set on fanjiao, manhuaku, bilibili_manga) is returned as `needs_browser` on each source; the Sources tab leaves such a source out of Search and turns off its chapter Import, with the existing browser install notice, while playwright or a browser is missing.

- Word timings: undo (restore a version, line history) and undoing a re-transcribe bring text back without words; "Merge short lines" and single-line re-transcribe store none; lines transcribed before the feature keep the estimate.
- Hallucination silence threshold: titles stored at the old default 2.0 were reset to 0 once; a deliberately chosen 2.0 must be set again.
- Browser-tier status (owner-reported 2026-10): Miaoqumh, GoDaManhua/Baozimh, Kuaikan and Zero-Sum Online are unverified against the live site; Bilibili Manga is unverified for the `mc<comic>/<episode>` reader; Piaotian's Cloudflare challenge is stopped by design (use a saved page).
- Parked import/export follow-ups (2026-09-30): the chapter list is fetched twice (only lightnovel_fun repeats real fetches); `media_export_service` builds in the system temp dir and moves across drives by copy; rows written before at-rest redaction are scrubbed on read only.
- Qwen3-ASR with its own speech detection (and anime-whisper, the ASMR detector and mixed-language runs) reads the whole file into RAM as 16 kHz audio, about 550 MB an hour at the decoding peak. A file that would need more than the free RAM is refused before decoding with a "split it into shorter files" message (`memory_headroom.check_whole_audio`). Chunked speech detection is planned after accuracy steps A2/A3, because it changes where lines are cut near chunk edges.
- The Characters merge confirm duplicates `db._folded_row`'s clip rule in `mergeSpeakers.ts` (`leavesVoiceClip`); update both if it changes.
- File sizes: the splits are finished. Every production `.py` file is under the 40 KB cap (`tests/test_static_analysis.py`), but eleven sit within 1 KB of it (largest: `live_translate.py`, `services/diagnostics_installs_service.py` and `api/auth.py`, about 40.9 KB each). `db/` is a package: `db/__init__.py` (30 KB) keeps the connection, `init_db` and the re-exports, with the schema in `db/schema.py` and `db/schema_system.py`, the migrations in `db/migrations.py` and one module per data domain (`docs/database.md`). `api/schemas/`, `engine_backends/` and `jobs/` are packages too.
